# Управление товаром

Карточки товаров показывают цену, полученную с Kaspi, отдельно от цены в XML.
Место рассчитывается по цене и рейтингу среди загруженных предложений, включая
магазины из белого списка. Белый список по-прежнему исключает магазины только
из расчёта новой цены. Время проверки указано в карточке; у выключенного бота
данные не обновляются.

Закупочная цена хранится отдельно и не меняет Min. Маржа в карточке:
`(цена − закупка) / цена × 100%`, без комиссии, налогов и доставки.

Автоснижение включено по умолчанию, автоповышение выключено. При выключенном
автоповышении цена XML, уже обеспечивающая первое место, сохраняется.
При включённом автоповышении бот может повысить цену до цели общей стратегии.
Переключатели действуют для всех городов конкретного товара. Min и Max имеют
приоритет: если старая цена вне новых границ, бот возвращает её в диапазон.
Основной переключатель бота и общая стратегия продолжают действовать.

Остатки, доступность и предзаказ редактируются для существующих складов. Новые
ID складов загружаются из XML магазина. Снятие доступности передаётся как
`available="no"`, а не удалением товара из прайса. Изменения применяются на Kaspi
после очередной загрузки XML. Заказы и функции кабинета, требующие авторизации
Kaspi, в этот релиз не входят.

Источники компоновки и функций: предоставленный скриншот AlgaTop и
https://algatop.kz/bot. Полное YouTube-демо недоступно для воспроизведения во
время реализации; проверены только доступный начальный кадр и скриншот.
