Project OverviewA high-performance automated repricing system for Kaspi.kz merchants. The tool monitors competitor pricing across multiple cities, applies smart pricing strategies (aggressive dumping, matching, maintaining position, white-listing merchants, and geo-targeted rules), and synchronizes price updates back to the merchant cabinet or XML feed.Technology StackBackend: Python 3.11+, FastAPI, Celery, RedisDatabase: PostgreSQL (with SQLAlchemy or Tortoise ORM)Scraping/Networking: httpx, curl_cffi (for TLS fingerprint bypass), and Playwright (fallback for anti-fraud/Cloudflare)Frontend / Dashboard (Optional/Future): React or Next.js with Tailwind CSSFull Technical Specification (ТЗ)1. Competitor Monitoring (Parsing Module)Target: kaspi.kz product cards (/p/... or internal API endpoints).Geo-Specificity: Must support filtering by cityId (Almaty: 750000000, Astana: 710000000, etc.) to match merchant warehouses and regional pricing.Proxy Management: Rotation of Kazakhstani residential/mobile proxies to avoid IP bans and CAPTCHAs.Data Extracted: List of competing merchants (merchantId, merchantName, price, rating, reviewCount, deliveryTime).2. Pricing Strategies (Rule Engine)For every product SKU, the system supports the following rules:"Стать первым" (Aggressive Dumping): Set price to $P_1 - \text{step}$ (default step = 1 ₸), subject to min_price."Цена первого места" (Match First Place): If merchant's rating is higher than the current 1st place, match their price ($P_1$) instead of undercutting."Прижиматься к первому месту" (Hold 2nd Place): Set price to $P_1 + 1$ (or follow top-1 closely) to capture orders via store reputation without starting a price war."Борьба за 2-20 место" (Fallback / Position Targeting): If $P_1 - \text{step}$ drops below min_price, search positions 2 through 20 for a viable price point $\ge \text{min\_price}$, or pin to min_price.3. Filters & Special RulesWhite List / Ignored Merchants (ignored_merchants): Array of merchant IDs to exclude from consideration (partner stores, own sister-stores).Stop-Loss / Min Price Safety (min_price): Absolute floor price incorporating product cost, Kaspi commissions (8-15%), tax, and fulfillment. No strategy can push prices below this limit.4. Sync & Update ModulePush calculated prices back to Kaspi via merchant session emulation or automated XML price list generation and uploading.Development Guidelines for ClaudeModularity: Keep scraper, rule engine, and database workers completely decoupled.Error Handling: Implement robust exponential backoff for network timeouts, proxy rotations, and rate limits.Type Safety: Use strict type hints (typing) across all Python code.Code-Only Output: When writing code, output complete, runnable files following the Single-File Mandate if applicable.
