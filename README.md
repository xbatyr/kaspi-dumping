# Kaspi Repricer

Репрайсер для магазинов на Kaspi.kz: следит за ценами конкурентов, считает свою
цену по выбранной стратегии и отдаёт Kaspi готовый прайс-лист.

Всё, что касается магазина, владелец заполняет **в панели**: ID магазина,
прокси, интервал, Telegram, выключатель бота. В переменных окружения остаётся
только то, что относится к серверу: адрес базы, ключ API и пароль панели.

| Что | Где | Зачем |
| --- | --- | --- |
| Движок цен | `repricer/pricing/` | считает цену, не опускаясь ниже минимума |
| Парсер Kaspi | `repricer/scraper/` | цены конкурентов, поиск карточек, прокси, повторы |
| Прайс-лист | `repricer/uploader/` | собирает XML и публикует его |
| Сервис | `repricer/service.py` | крутит циклы по настройкам из базы |
| API | `repricer/api/` | настройки, товары, правила, история, фид |
| Панель | `frontend/` | всё то же самое мышкой |
| Бот | `repricer/telegram/` | алерты и команды в Telegram |

## Запуск на сервере (рекомендуемый путь)

```bash
cp .env.example .env     # задайте POSTGRES_PASSWORD, REPRICER_API_KEY, DASHBOARD_PASSWORD
docker compose up -d
```

Поднимутся база, миграции, API, воркер, Telegram-бот и панель. Дальше владелец
открывает панель, вводит данные магазина — и всё начинает работать само.

> Файлы `Dockerfile` и `docker-compose.yml` написаны, но на машине разработки
> Docker Engine недоступен на машине разработки, поэтому запуском они не проверены. Первый `docker
> compose up` стоит сделать вдумчиво.

Наружу нужно открыть только два адреса: панель (за паролем) и `/feed/kaspi.xml`
(его забирает Kaspi без авторизации). Всё остальное в API закрыто ключом.

## Запуск вручную (для разработки)

Нужны Python 3.11+, PostgreSQL и Node 20+.

```bash
cp .env.example .env
pip install -e ".[dev]"
alembic upgrade head

uvicorn repricer.api.app:app --port 8000     # API и фид
repricer                                     # воркер, настройки берёт из базы
repricer-bot                                 # Telegram, токен тоже из базы

cd frontend && npm install && cp .env.example .env.local && npm run dev
```

Панель спросит логин и пароль (`DASHBOARD_USER`, по умолчанию `owner`). Защита
живёт в `frontend/src/proxy.ts` — в Next 16 это новое имя для `middleware.ts`,
старое молча игнорируется, и панель останется открытой, если файл переименовать
обратно.

## Что делает владелец магазина

1. **Настройки** — ID магазина на Kaspi, название компании, при желании рейтинг,
   прокси, Telegram. Пока ID и название не заполнены, бот не запустится.
2. **Добавить товары** — загружает полный XML-прайс Kaspi: «Добавить товары» →
   «XML Kaspi» → «Проверить XML» → «Импортировать». ID магазина в настройках
   должен совпасть с `<merchantid>` в файле. Существующие стратегии не
   перезаписываются; цены новых товаров сохраняются как ручные. Импорт принимает
   пространство имён `kaspiShopping`, `stockCount="2.0"` (если число целое) и
   пустой бренд из выгрузки `ACTIVE.xml`. Опция «Брать ID карточки из первой
   части SKU» подходит для SKU вида `130342357_673822557`; число привязанных
   карточек видно до импорта. Либо вводит
   название, нажимает «Найти», выбирает карточку из
   результатов Kaspi: ID карточки, название и бренд подставляются сами. Или
   вставляет таблицу из Excel, где можно сразу задать город, стратегию и Min/Max.
   Колонки понимаются по-русски (`sku`, `название`, `id_kaspi`, `бренд`, `склад`,
   `остаток`, `город`, `мин_цена`, `макс_цена`, `стратегия`).
3. **Привязать карточки**, если ID нельзя извлечь из SKU: у товаров без ID нажимает
   «Привязать» и вводит цифровой ID из ссылки на публичную карточку Kaspi.
   Без него поиск цен конкурентов и автоматический демпинг для товара не
   включаются. После привязки выбирает стратегию и границы Min/Max.
4. Во вкладке **Стратегии** один раз задать стратегию, города и белый список
   магазинов, исключаемых из расчёта. Затем для каждого товара задать свои
   безопасные Min/Max и шаг изменения цены. Их можно изменить прямо под ценой
   в списке товаров: наведите на цену или нажмите её. Импортированные товары без этих границ остаются в ручном
   режиме. Кнопка с часами в таблице показывает историю цен; галочками можно
   выбрать несколько товаров и задать им границы вместе.
5. **Включает репрайсер** в настройках. Пока общий переключатель выключен или
   общая стратегия не сохранена, воркер не пересчитывает цены. Сверху всегда видно: сколько товаров попадёт в
   прайс, что мешает остальным, сколько позиций на первом месте и ссылку для
   кабинета Kaspi.
6. **Вставляет публичную HTTPS-ссылку** `/feed/kaspi.xml` в кабинет продавца: Товары → Загрузка
   прайс-листа → Автоматическая загрузка.

Прайс должен содержать весь ассортимент, который Kaspi должен получать через
этот источник. Если активный товар нельзя включить в XML из-за отсутствия
склада или цены, эндпоинт вернёт 503 и не отдаст неполный прайс. XML формируется
по схеме Kaspi: для товара указывается либо общая `<price>`, либо
`<cityprices>`; пустой бренд опускается.

Выключатель бота и любые настройки применяются со следующего цикла —
перезапускать ничего не нужно.

Telegram-бот — отдельный процесс (`repricer-bot`). Один токен берётся из
`TELEGRAM_BOT_TOKEN` или ранее сохранённой записи базы; в панели токен не меняется.
Любой пользователь, который отправит боту `/start`, подписывается на сообщения
о реально записанных изменениях цен; `/unsubscribe` отключает их. Команды
управления доступны только chat ID владельцев из настроек. Сам бот не включает
репрайсер; на локальном запуске его нужно запустить отдельно.

## Тесты

```bash
TEST_DATABASE_URL=postgresql+psycopg://localhost/repricer_test pytest
mypy repricer tests scripts alembic
cd frontend && npm run lint && npm run build
```

Тесты базы пропускаются без `TEST_DATABASE_URL`. Указывайте одноразовую базу:
тесты пересоздают в ней таблицы.

## Чего ещё нет

- **Скорость.** Цены уезжают через прайс-лист, который Kaspi забирает примерно
  раз в час. Конкуренты вроде AlgaTop обновляют за минуты, но делают это через
  кабинет продавца — для такого нужен логин и пароль магазина и отдельный модуль.
- Один магазин на установку: таблицы магазинов, пользователей и тарифов нет.
- Позиция на витрине — расчётная (какой её ожидал движок), фактическая после
  смены цены не перепроверяется.
- Токен Telegram и пароли прокси лежат в базе открытым текстом: держите базу
  закрытой.
- Фид ни разу не загружался в реальный кабинет Kaspi — формат сверен с
  документацией, но подтвердить стоит одной тестовой загрузкой.
